Privacy Policy: Statement Fetcher

Last updated: 20 October 2026

Statement Fetcher (“the app”) is a personal tool written and used by one person, its developer. It is not offered to the public and has no other users. This policy explains what Google user data the app accesses, how it is used, where it is stored and how long it is kept.

1. Google user data the app accesses

  • Gmail messages and attachments (read-only). The app searches the owner's own mailbox for bank statement emails and reads the PDF attachments on those emails. It uses the gmail.readonly scope, so it cannot send, modify or delete any email.
  • Google Drive files the app creates. The app saves unlocked statement PDFs into a single Drive folder it creates. It uses the drive.file scope, so it can only see files it created itself, and no other files in Drive.
  • Basic sign-in token. To act on the owner's behalf without asking each time, the app keeps a Google OAuth token, stored as an encrypted secret.

2. How the data is used

The data is used for one purpose only: to find the owner's bank statement emails, remove the PDF password and save a copy to the owner's own Google Drive, so the owner can keep their statements in one place for personal budgeting. The data is not used for advertising, profiling, analytics or any other purpose.

3. Sharing and disclosure

The data is not sold, rented, transferred or disclosed to any third party. It is processed on GitHub’s servers (GitHub Actions) and saved only to the owner’s own Google Drive. No humans read the data other than the owner.

4. Google API Services User Data Policy

Statement Fetcher’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. Storage, security and retention

  • Processing. Statements are processed in memory on a temporary GitHub machine that is discarded after each run. No statement PDFs are kept on it.
  • Secrets. The statement password and the Google sign-in token are stored as encrypted GitHub secrets in a private repository and are never published.
  • Run logs. Each run’s log lists the names of the statement files it saved. If a statement cannot be unlocked, the log also shows that email’s subject line and attachment name. GitHub keeps these logs for its standard retention period. They are visible only to people with access to the private repository, and the owner can delete them at any time.
  • Local runs. If the owner runs the app on their own computer, it also keeps unlocked PDF copies, a record of the emails already handled and a log file on that computer until the owner deletes them.
  • Google Drive. The unlocked PDFs remain in the owner’s Drive folder until the owner deletes them.

6. Your choices and deleting data

The owner can stop the app at any time by disabling the scheduled job, can revoke its access at myaccount.google.com/permissions, and can delete the saved statements from Google Drive and the run logs from GitHub. Revoking access immediately stops the app from reading Gmail or writing to Drive.

7. Changes to this policy

If the app’s use of data changes, this page will be updated and the date above changed.
